## 4. Script Guardrails & Automatic Teardown

To ensure test data is never accidentally injected into production or retained in storage:
1. **`scripts/test-contribution-integration.mjs`**: Hardcoded to `http://127.0.0.1:8787`, tracks all generated submission IDs and automatically cleans them up from local storage at test completion.
2. **`scripts/test-browser-submission-flow.mjs`**: Runs full simulation against local Worker and safely removes the simulated submission in a `finally` block.
3. **`scripts/test-pdf-and-zip-submissions.mjs`**: Runs multi-format tests and cleans up test objects upon test exit.
4. **`scripts/seed-firebase-materials.mjs`**: Confirmed; only manages official curriculum materials and subjects, never touches student contributions.
